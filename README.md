# English Tenses — 12 thì tiếng Anh

Website học tập giới thiệu 12 thì tiếng Anh, chia thành 3 nhóm: **Hiện tại**, **Quá khứ** và **Tương lai**.

## Các trang
- `index.html`: Trang chủ và tổng quan 3 nhóm thì.
- `present.html`: 4 thì hiện tại.
- `past.html`: 4 thì quá khứ.
- `future.html`: 4 thì tương lai.
- `style.css`: Giao diện responsive, bảng màu lạnh, font Arial.
- `script.js`: Menu điều hướng trên thiết bị di động.

## Chạy website
Mở `index.html` bằng trình duyệt. Các trang được tách thành những tệp HTML riêng biệt và liên kết với nhau qua menu.

## Bật GitHub Pages
1. Mở **Settings** của repository.
2. Chọn **Pages** ở thanh bên.
3. Trong **Build and deployment**, chọn **Deploy from a branch**.
4. Chọn branch `main` và thư mục `/(root)), sau đó nhấn **Save**.
5. Sau khi GitHub Pages triển khai xong, website sẽ có địa chỉ:
   https://dangkhoinguyen7511.github.io/english-tenses-12/
